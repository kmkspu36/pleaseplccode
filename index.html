미쓰비시 PLC(GX Works2 / GX Works3) 작업을 하나의 AI 채팅에서 요청하세요. 작업을 선택하면 요청 문구가 채팅 입력창에 채워지며, 내용을 확인한 뒤 직접 전송합니다.

PLC 코드 작성

제어 요구사항을 입력하면 AI 채팅 입력창으로 요청을 보냅니다.

오류 검사

코드와 오류 증상을 입력하세요.

자동 오류 수정

오류가 있는 코드를 입력하세요. 원본은 자동으로 덮어쓰이지 않습니다.

래더 작화

미구현

래더 다이어그램 미리보기는 아직 구현되지 않았습니다. 에이전트가 래더 작화를 지원하는지도 확인되지 않았습니다.

래더 로직 설명은 "PLC 코드 작성"에서 일반 채팅 요청으로 시도할 수 있습니다.

도면 분석

지원 여부 미확인

도면 파일은 채팅 입력창의 첨부 버튼으로 보낼 수 있습니다. 에이전트가 첨부 파일을 실제로 읽을 수 있는지는 아직 검증되지 않았습니다.

프로젝트 관리

프로젝트 이름은 이 브라우저에만 저장됩니다. 서버나 에이전트, 다른 기기와는 동기화되지 않습니다.

작업 기록

이 화면에서 채팅 입력창에 넣은 요청의 기록입니다. 이 브라우저에만 저장되며 에이전트 대화 기록과는 별개입니다.
